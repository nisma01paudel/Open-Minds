# Benchmark

Two site sets, both required for any honest number:

- `events.csv` — slopes/road segments with a **documented failure date** and coordinates, each cited.
- `controls.csv` — matched slopes (elevation, slope, aspect, land cover) with **no recorded failure**.

Controls are what make a false-alarm rate meaningful. Status: event inventory sourcing in progress;
see `docs/DATA.md` for data risks.
